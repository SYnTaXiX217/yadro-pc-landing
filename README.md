# Ядро — лендинг сборки игровых ПК

Адаптивный одностраничный сайт вымышленной студии, которая собирает игровые компьютеры. Учебный проект для портфолио.

**Демо:** https://syntaxix217.github.io/yadro-pc-landing/

## Что внутри

- Калькулятор: ползунок бюджета подбирает сборку (процессор, видеокарта, память, SSD) и показывает ожидаемый FPS
- Шар, который плавно меняет цвет и размер вместе с бюджетом
- Плавные анимации: появление заголовка, счётчик цены, появление блоков при скролле
- Светлая и тёмная тема (подстраивается под систему)
- Адаптивная вёрстка для телефонов и планшетов
- Форма заявки с проверкой полей
- Учтена настройка `prefers-reduced-motion`

## Технологии

HTML5, CSS3 (custom properties, `@property`, grid, `backdrop-filter`), JavaScript без библиотек и фреймворков.

## Структура

```
index.html   разметка страницы
style.css    стили и анимации
script.js    калькулятор, плавные переходы, форма
```

## Запуск

Откройте `index.html` в браузере. Сборка не нужна.

## Что можно доработать

- Отправка заявок в Telegram через небольшой сервер (токен бота нельзя хранить в клиентском JS)
- Реальные цены комплектующих из таблицы или API
